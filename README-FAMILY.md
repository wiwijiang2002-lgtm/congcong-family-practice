# 聪聪学堂 · 二年级上册家庭练习体验版

本地 MVP：**统编语文 + 苏教数学**。新增一周错题同类巩固与隔日独立复测，以及家长本地导入练习册题库。家长布置 → 孩子作答 → 客观题自动判分 → 错题与仿写记录 → 家长看结果。可从任何课文直接开始，无须先通过《小蝌蚪找妈妈》。

## 运行

需要 Node.js 22（本机已安装）。在本文件所在目录打开终端：

```powershell
npm.cmd ci
npm.cmd run family:build
npm.cmd run family:start
```

浏览器打开 http://localhost:4173 。已经有 `apps/family/out/index.html` 时，跳过安装与构建，只运行 `npm.cmd run family:start`，也可双击 `启动家庭练习.cmd`。

开发模式：`npm.cmd run family:dev`，同样使用 4173 端口。不要同时启动开发和静态服务。

同一 Wi-Fi 下，iPad Safari 可以打开 `http://电脑的局域网IPv4地址:4173`。按电脑现有网络策略允许本地访问即可。**电脑的 localhost、电脑的 IP、iPad 属于不同浏览器或来源，数据不互通。**要在 iPad 演示整个闭环，请在 iPad 内切换家长端和孩子端。

## 推荐演示顺序

1. 切换「家长端」→「按课文选题」，直接搜索后面的《登鹳雀楼》《纸船和风筝》等。
2. 打开某课，阅读知识拓展，点击「用这课布置练习」。可取消题目，也可补充老师要求的词语、拼音提示或背诵短片段。
3. 设置当天日期并布置，切到「孩子端」→「今天的练习」开始作答。
4. 看拼音默写、生字填空、古诗片段默写；数学使用选择题和数字键盘；仿写输入自己的句子。
5. 检查答案并看解释。仿写只记录原文，不机械判分。
6. 最后一题点击「完成练习，查看结果」。故意答错一题，查看「我的错题」，再练答对后该题移出错题列表。
7. 回「家长端」→「学习结果」，查看得分、每题原始作答和仿写原文；点击「导出学习报告」，下载后用浏览器打开阅读或打印。
8. 练习中刷新或「保存并离开」，再点「继续练习」验证续做。

孩子端另有「自由选课」，任意后续课文都能直接开始自主练习，不伪造前面课文的完成记录。

## 课程与题库范围

- 仅二年级上册。统编语文按上游 **2026 秋版**目录整理 29 个主课文/古诗条目（古诗二首按篇拆开）；苏教数学按新课标 6 个核心单元提供 24 道示例题。
- 每个语文条目包含：两道拼音提示的词语默写、一道生字填空、一道仿写拓展；部分古诗另含公开领域的原诗片段默写；每篇配一段知识拓展。
- 词语、题目、解释、仿写参考句为本体验版自编演示内容，**不是官方生字表、必默清单、整册课后习题或教师审核题库**。必背内容以孩子课本与老师要求为准；家长可在布置页补充。
- 未复制现代课文全文、教材图片、上游原页、音频或故事资源包。语文园地、补充阅读和数学综合实践活动尚未覆盖。
- 苏教版数学新旧版差异较大；本版采用「1～6 表内乘法、1～6 表内除法、7～9 表内乘除法、认识三位数、两位数加减、有余数除法」核心单元参考。若学校仍用旧版，需要替换课程目录与题目配置。

## 数据与判分

- 练习记录与本地题库分开保存，互不覆盖：练习记录键 `congcong-family-demo:v1`；家长导入的题目键 `congcong-family-local-bank:v1`。上游 `csf-*` 学习记录不会被清空。题目快照随练习和结果保存。
- 客观题每题 10 分，仿写 0 分且判分状态为 `null`，单独标记「待交流」，不计入正确率或错题。
- 默写忽略空格、常见标点和字母大小写，汉字逐字准确比较，不自动接受同义表达或繁简转换。
- 复用上游选择/文字判分；数学使用局部严格数值适配器，拒绝错误分数、带无关字符和不完整的输入，支持等值数值。
- 作答与已判状态逐次保存；提交结果有去重保护。错题按同一题最近一次完成的作答更新，历史成绩不改写。每轮错题复习最多 12 道。
- 存储不可用会明确显示「页面内暂存」提示，可导出 JSON；损坏数据不静默覆盖，可先导出原始记录再重置。
- 「学习结果 → 导出学习报告」下载可离线阅读的中文 HTML 报告，包含得分、逐题原始作答、参考答案、解析及仿写原文；打开报告后可打印或另存为 PDF。单次结果页可「导出本次报告」。
- 「设置 → 导出数据备份（JSON）」只保存练习记录，不包含导入的本地题库；题库要在「我的题库」中单独导出备份。本版尚未提供练习记录备份导入界面。「重置体验数据」只操作练习记录，不删除本地题库。
- 用时为从开始到完成的墙钟时间，包含休息；不是有效专注时长。

## 家长本地题库与弱点建议（新版）

家长端新增「我的题库」。可把购买练习册的题目整理成表格后导入当前浏览器，再勾选布置，或在孩子端「自由选课」中按单元练习。

1. **导入方式**：从 Excel/WPS 复制含表头的题目区域直接粘贴；或导入 CSV / TSV / JSON 文件。程序先按 UTF-8 读取，失败时自动尝试 GBK，兼容中文 Excel 的 CSV。单个文件最大 2 MB。
2. **必填列**：学科、题型、题干、答案；选择题再填 2–4 个选项。可选：知识点、解析、单元、作答方式。完整格式、示例和限制见 [本地题库导入说明.md](本地题库导入说明.md)，程序内也可下载 CSV/JSON 模板。
3. **判分**：客观题每题 10 分；仿写 0 分，只记录原文。选择题答案可填 A–D 或与选项完全一致；数学填空必须能解析为数字；语文填空/默写使用文字输入。无法自动判分的行在导入预览中列出并跳过，不会静默生成错题。
4. **布置与自由选课**：导入后可按题库搜索、勾选题目布置（每份最多 12 道）；题目上的“单元”会生成孩子端的本地课程卡片，每个单元单次最多取前 12 道，并明确提示总数。
5. **一周巩固边界**：本地题库的错题会按知识点出现在「一周巩固」，但标记为“待补充同类题”。系统不会为购买题目编造同类新题，也不会把订正原题当作掌握；本地题库题目目前不参与自动变式或隔日复测；自动巩固仍只覆盖内置的语文词语/古诗和数学计算技能。
6. **隐私与备份**：题目和答案只写入当前浏览器 `congcong-family-local-bank:v1`，不上传服务器、不进入公开仓库。题库页可导出含答案的 JSON 备份（只应保存在家长设备）；换设备需重新导入。删除题库不影响已布置练习和结果，因为布置时已保存题目快照。
7. **弱点建议练习**：家长端「练习安排」会根据最近 7 天的错题，从本地题库寻找知识点相近、还没有布置过的题，最多建议 3 个知识点、每个知识点 3 道（不足时按实际可用题数）。家长先预览题目和答案，点“用这 N 道准备练习”进入布置页调整，确认后才发布；系统不会自动布置。匹配使用知识点、技能关键词和题干文字比对，同单元题目优先，不是 AI 语义理解；题目没有标注知识点时，会优先按同单元、其次按同题库回退，并在卡片上提示核对。内置数学弱点也能匹配本地题库中带“乘法”“除法”“余数”等标签的题。

## 已知限制与下一步

这是单设备角色模拟，没有真实账号、家长密码、权限隔离或跨设备同步。答案也随前端资源存在，适合家庭练习体验，不能用于正式考试。没有手写/Apple Pencil 识别、语音听写、语音判分、自动作文判分、CloudBase、微信、推送、邮件或付费 API。

本地题库暂不支持直接读取 XLSX、PDF 或图片（需先另存 CSV 或粘贴表格），不做 OCR；不支持判断题、多选题、连线、排序和多答案；同一题只有一个可接受答案。本地题库也没有自动同类变式，一周巩固会如实显示“待补充同类题”。

弱点建议用知识点、单元和技能关键词做文字匹配，不是 AI 语义理解，也不验证题目难度和答案是否正确。题库没有标注知识点、标签太笼统、或同知识点未做题不足时，建议可能为空或不足 3 道；家长必须在布置页核对后再发布。

建议下一步先用 **SQLite + 一个小型本地服务**：建立 `households`、匿名 `learners`、`question_versions`、`assignments`、`assignment_questions`、`attempts`、`responses`、`writing_reviews` 表；保留不可变题目快照和题目版本，把判分与提交去重移到服务端，使用事务写入原始作答、得分和错题状态；用家长密码/会话控制读写边界。由电脑提供局域网服务，iPad 和家长设备才共享同一数据源。随后再按实际部署需求迁移 PostgreSQL/云数据库，无须先引入付费云能力。

连接数据库前先复核学校实际教材版次、生字表与背诵要求；增加教师/家长内容审核、拼音多音字说明、仿写评语与订正记录。验证报告见 [VALIDATION.md](VALIDATION.md)。

## 报告导出更新

旧版「导出数据」下载的是 JSON 程序备份，容易被误认为代码。新版默认导出中文学习报告（HTML），不再要求家长阅读备份内容。原 JSON 导出放在设置中，明确标为「导出数据备份（JSON）」。

升级：关闭原启动窗口，解压新版体验包并启动，继续使用原浏览器和原网址（例如 http://localhost:4173）。数据结构和保存键未改变，无需重置，已有练习结果可直接导出报告。只替换应用文件即可，勿清除浏览器网站数据。

## 一周错题巩固（新版）

家长端、孩子端均新增「一周巩固」。按**包含今天的最近7个本地日历日**汇总错答，按具体知识点归类，不把“原题记住了”直接等同于同类验证通过。

1. 家长点「安排本周巩固」，或对一个知识点点「安排这类新题」。每次最多3个知识点，每项2道未做过的同类新题。孩子也可在该页直接开始巩固。
2. 同类巩固会逐题显示判分和讲解。某个知识点的2题均答对后，显示「待隔日复测」。单个知识点的通过情况独立统计，不用整份总分替代。
3. 家长可立即安排「隔日复测」，但孩子必须与同类练习的完成时间间隔**至少24小时**才能进入。系统保留待完成任务，即使原错题已经超过7天。
4. 独立复测使用另2道未见题，过程中仅显示“答案已记录”，不提示对错、不显示参考答案和解析；全部提交后统一看结果。
5. 两题都正确才显示「本轮复测通过」。再错则回到继续巩固，出现新的同知识点错答也会使旧证明失效。已经失效的旧复测不能继续使用。
6. 「导出一周巩固报告」生成中文可读HTML，包含知识点进度、原题/同类练习/独立复测表现和相关逐题记录，仍可打印或另存为PDF。

**题目适配范围**：数学按进位加法、退位减法、不同类型的乘除法、数位和余数等知识点换数字或情境；优先选接近原错题的乘法表。交换乘数的同一算式会去重。语文针对同一易错字词换词义/语境默写，古诗采用不同空位及整句背诵。每题保留来源与新题签名，已安排过的题不会再次用作“未见新题”。

新增变式为本地规则和自编句子生成，不调用AI或付费API，不是已审核的整册习题。部分家长补充题尚无配套变式时显示「待补充同类题」；未见新题用完会提示扩充题库，不会反复用旧题凑数。「本轮复测通过」只表示这次两道新题通过，不能证明全部知识已长期掌握，仍建议结合后续学习观察。原题错题本与仿写记录保留；仿写不参与自动掌握判断。

旧版本本地数据可直接读取，仍使用原保存键；升级无需重置。

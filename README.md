# 聪聪学堂 · 在线家庭练习

统编语文、苏教数学二年级上册。包含家长布置、孩子练习、可读报告、一周错题同类巩固与隔日独立复测。

在线体验：https://wiwijiang2002-lgtm.github.io/congcong-family-practice/

无需登录，持链接即可访问。iPad 用 Safari 打开即可，电脑无需运行 CMD 或保持开机。国内网络直连的稳定性需用实际网络验证。

学习记录仅保存在当前浏览器；上线不会自动迁移原 localhost 的记录，不提供跨设备同步。

## 维护

Node.js 22，npm ci 后运行 npm run dev；npm test 验证，npm run build 生成 dist。静态托管目录为 dist。

已通过 GitHub Pages 公开部署，仓库 main 分支的程序改动会自动构建并发布。工作流自动处理仓库网址的子路径。详见 DEPLOYMENT.md。更换开发工具（例如 DeepSeek Harness）可先阅读 HANDOFF.md。

# 聪聪学堂 · 在线家庭练习

统编语文、苏教数学二年级上册。包含家长布置、孩子练习、可读报告、一周错题同类巩固与隔日独立复测，以及家长本地导入练习册题库和按弱点生成建议练习。

在线体验：https://wiwijiang2002-lgtm.github.io/congcong-family-practice/

无需登录，持链接即可访问。iPad 用 Safari 打开即可，电脑无需运行 CMD 或保持开机。国内网络直连的稳定性需用实际网络验证。

学习记录仅保存在当前浏览器；上线不会自动迁移原 localhost 的记录，不提供跨设备同步。

## 家长本地题库

家长端「我的题库」可导入购买的练习册题目，支持从 Excel/WPS 复制粘贴、CSV/TSV 文件和 JSON。**题目与答案只写入当前浏览器的 `localStorage`，不上传服务器，也不会进入公开仓库。**换设备、换浏览器或清除网站数据后需要重新导入；请用题库页的“导出备份”保留副本。

导入格式、判分范围、隐私边界和需要提供的真实题目文件格式见 [本地题库导入说明.md](本地题库导入说明.md)。本地题库暂不自动生成同类变式，错题在一周巩固中显示“待补充同类题”，不会伪造掌握状态。

家长端「练习安排」还会根据最近 7 天错题，从本地题库寻找同知识点、尚未布置过的题，生成最多 3 道建议练习。建议只打开布置页供家长核对，不会自动发布；匹配使用知识点/技能关键词和题干文字比对，同单元题目优先；题目没有知识点标签时会按同单元或同题库回退并提示核对。

## 维护

Node.js 22，npm ci 后运行 npm run dev；npm test 验证，npm run build 生成 dist。静态托管目录为 dist。

已通过 GitHub Pages 公开部署，仓库 main 分支的程序改动会自动构建并发布。工作流自动处理仓库网址的子路径。详见 DEPLOYMENT.md。更换开发工具（例如 DeepSeek Harness）可先阅读 HANDOFF.md。
